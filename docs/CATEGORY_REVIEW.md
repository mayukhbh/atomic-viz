# Element category review

Reviewed 2026-11-06. All 118 category assignments inventoried below. No category changes applied: the named families agree with the references; the remaining boundary choices need an explicit scientific/editorial convention, not a silent color change.

Sources:

- [IUPAC periodic table and collective names](https://iupac.org/what-we-do/periodic-table-of-elements/): group numbers, La–Lu and Ac–Lr ranges, and group-3 uncertainty.
- [IUPAC Red Book collective names, IR-3.6.2](https://old.iupac.org/reports/provisional/abstract04/RB-prs310804/Chap3-3.04.pdf): named families and transition series (historical document, predates Ts/Og).
- [IUPAC transition-element definition](https://goldbook.iupac.org/terms/view/T06456): classification depends on incomplete d subshells in atoms or cations, not simply being in the d block.

Review decisions:

- Group 1 except H, group 2, halogens and noble-gas columns: retain. Ts/Og labels describe group placement, not measured noble-gas/halogen behavior.
- La–Lu and Ac–Lr: retain. Existing `Lanthanide`/`Actinide` display names are widespread synonyms; no user-facing copy change.
- Zn, Cd, Hg, Cn: current `Transition Metal` follows a broad d-block convention. Proposed follow-up: distinguish d-block membership from the stricter IUPAC transition definition. Do not automatically move all four to `Post-transition Metal`; that would conflate conventions and superheavy predictions. Source: Gold Book above.
- Po: current `Metalloid` lies on a convention-dependent boundary. Proposed follow-up: agree a reference table for metalloid vs post-transition categories before changing it. IUPAC's group numbering does not settle this app-specific ten-color partition.
- Nh–Lv categories are group-position predictions; preserve rather than imply experimentally settled bulk chemistry.
